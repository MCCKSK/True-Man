TrueMan 项目说明文档（AI 极简版）
（把本文件交给任何 AI，它就能快速理解这个游戏的需求、结构、和设计约定）

【一、必读与用户画像】
1) 本文件仅供参考，一切以当前 main.py 为准。修改前必须完整读取 main.py。
2) 用户是编程小白，禁止输出大段代码或完整 main.py，必须提供 patch.py 补丁。
3) 补丁机制：用户将 patch.py 与 main.py 同目录双击运行。逐条字符串替换并打印数量。
   - 不生成 main.py 备份。
   - 全部替换成功：按回车后自动删除 patch.py（自毁）。
   - 出现"未找到"：保留 patch.py，提示用户反馈编号，AI 需按当前 main.py 重新对齐匹配串。
4) 交互要求：禁止一切 emoji，注释必须用中文。

【二、项目概况】
- 语言：Python 3 + pygame，单文件 main.py。
- 窗口：800x600，FPS=60（所有时间以帧为单位）。
- 资源目录：./temp/（含版本号 NONJ.config、字体、图、音效等）。
- 配置文件：settings.config（按键映射+端口+IP）。

【三、核心术语（状态与技能）】
1. 技能三种形式：
   - 普通技能：按一下 -> 触发 -> 冷却。
   - 存储技能：按一下扣次数 -> 次数 0 进冷却 -> 冷却结束重置次数。
   - 持续技能：按一下进状态 -> 持续N帧 -> 再按/受击提前结束 -> 进冷却。
2. 状态：
   - 无敌：半透明，不受任何攻击（不扣血、不位移、投射物穿透）。
   - 抓取：受控，除逃脱外按键全部失效。扣血但不击飞。

【四、状态机与架构】
- 状态常量（如 MENU, FIGHT 等）：主循环事件处理必须用 elif 链（FIGHT_KO 除外）。
- 角色系统：基类 Character，子类 Chr/Gjl/Wyk。用 get_char_class 获取。
- 数据驱动：从 character_data.json 读取（num, name, show_name, speed, jump_speed, attack, stand_up, skills）。
- 相机：世界宽 MAP_W=1000，屏幕 800。联机 2:1 跟随本机角色，本地/单人锁定中央。
- 按键映射：全局 keymap 字典，禁止硬编码键码。

【五、战斗核心机制】
- 受击保护：累计伤害达到 10000/15000/30000 时，后续伤害打折。
- 落地弹跳：根据保护等级决定还能弹几下（无/一级弹2下，二级弹1下，三级不弹直接起）。
- 逃脱：仅在受击时可用，瞬间落地 + 短暂无敌。
- 起身无敌：每次从倒地成功站起后获得短暂无敌。

【六、局域网联机（极易漏掉的要点）】
1. 架构：主机跑全部战斗逻辑，每帧发 STATE；客户端发 INPUT，本地不跑逻辑只绘制。
2. 身份：用 network_is_1p 判断谁是1P，绝不依赖 host/client。1P 永远用 p1 键位，2P 用 p2 键位。
3. 【强制同步检查】任何技能/角色/机制改动，必须检查：
   - 新增状态变量：__init__ 初始化、reset_character_for_battle 清零、build_network_state 打包、apply_network_state 接收。
   - 新增投射物列表：STATE 打包、客户端重建、客户端绘制。命中由主机判定。
   - 新增前摇/专用图：主机和客户端绘制都要加。
   - 新增 CD：必须同步。
   - 震屏：主机触发，客户端用 STATE 复现。
4. 粒子推断：爆炸、白烟、蛋碎不走网络。客户端靠对比相邻两帧 STATE 的位移/消失来本地生成。
5. 三个坑：apply_network_state 要加 global 声明；get_flip 缓存要在 Surface 上；新增 CD 不要只写单机端。

【七、版本与音效】
- 版本校验：NONJ.config 第一行。parse_version 与 compare_version。
- 规则：数字比较 -> 无后缀最大 -> 已知后缀(alpha<beta<rc) -> 未知后缀（默认高于已知，低于无后缀）。
- 音效：play_sfx(name, category)，加载失败静默跳过。客户端通过 STATE 对比 skill_trigger_seq 本地播放。

【八、硬性修改约定】
1) 改动尽量小、局部化。
2) 补丁字符串必须逐字对比 main.py，不要凭记忆写。
3) 音频判断用 audio_available，try/except 保护。
4) 字体用 get_font(size) 获取缓存，不要每帧 new。
5) 半透明绘制必须先 img.copy() 再 set_alpha。
6) 按键边沿触发（xxx_pressed 布尔字段）。
7) 所有按键通过 keymap 读取。

【九、代码结构快速索引】
1. 初始化、常量、状态、版本、按键映射
2. 工具函数（图片翻转/缩放、字体、按钮绘制、粒子缓存）
3. 属性图、通用类（ZoomShake / Button / SkillIcon / DamageNumber）
4. Character 父类（移动/攻击/受击/物理/冷却）
5. 资源加载（角色头像、地图、印章、携带技能、音效）
6. 主循环（事件处理 + 绘制）
7. 战斗循环（FIGHT 状态）
8. 联机模块（net_send / build_network_state / apply_network_state / draw_client）
